Platform Compatibility

                            
This tool is fully client-side. Only platforms with public caption endpoints work without a backend.

                            
    
                                
  • 
                                    YouTube — Supported
                                    Manual and auto-generated (ASR) tracks via the public timedtext / player response captions list.
                                
    • 
                                
  • 
                                    Vimeo — Supported
                                    Text tracks from the public player config JSON when captions are enabled on the video.
                                
    • 
                                
  • 
                                    Dailymotion — Supported
                                    Subtitle URLs from the public player metadata endpoint.
                                
    • 
                                
  • 
                                    Netflix, Disney+, Hotstar, etc. — Not Supported
                                    DRM-protected streams and authenticated APIs cannot be accessed from a static browser page. We do not fake support.

Formats Explained

                            
    
                                
  • 
                                    SRT (SubRip)
                                    Most compatible subtitle format. Numbered cues with HH:MM:SS,mmm timestamps. Works in players, editors, and most caption tools.
                                
    • 
                                
  • 
                                    VTT (WebVTT)
                                    Web standard used by HTML5 <track>. Timestamps use a dot decimal separator.
                                
    • 
                                
  • 
                                    TXT
                                    Plain transcript with no timestamps — ideal for reading, search, or feeding into other tools.
                                
    • 
                                
  • 
                                    RAW
                                    Original payload from the platform (JSON / XML / VTT) before conversion.
                                
    • 
                            


                            
FAQ

                            

                                

                                    Does this work for auto-generated YouTube captions?
                                    
Yes. ASR tracks appear in the language list and are labeled as auto-generated when the platform exposes that flag.

                                

                                

                                    Why might fetch fail?
                                    
Private/unlisted videos, region locks, missing captions, or temporary platform/network limits can block retrieval. Try another public video or language if one track fails.

                                

                                

                                    Is anything uploaded to a server?
                                    
No account, no login, and no SilenVault account storage of your URL. The tool runs in your browser like the other SilenVault utilities.
